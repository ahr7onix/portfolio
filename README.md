## 🗂️ Como este repositório está organizado

| Caminho | O que é |
|---|---|
| `index.html` | Página inicial do portfólio |
| `assets/js/projetos.js` | Lista de projetos exibidos no site. Para incluir ou esconder um projeto, edite este arquivo (`publico: true/false`) |
| `assets/projetos/` | Capturas de tela dos projetos |
| `Nexus/` | Código do projeto Nexus |

Para rodar localmente: `python -m http.server 8000` e abra http://localhost:8000.
